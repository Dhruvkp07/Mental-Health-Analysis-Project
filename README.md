# Mental Health and Lifestyle Analysis

An exploratory analysis of synthetic daily lifestyle and mental health data. The notebook provides a practice setting for examining variables such as sleep, screen time, exercise, workload, mood, and stress.

**Format:** Jupyter notebook · CSV dataset · exported plots

## Explore the project

| File | Purpose |
| --- | --- |
| [Mental Health Analysis.ipynb](Mental%20Health%20Analysis.ipynb) | Analysis notebook with visualizations. |
| [synthetic_mental_health_dataset.csv](synthetic_mental_health_dataset.csv) | Synthetic daily records. |
| [PLOTS.zip](PLOTS.zip) | Collection of exported plots. |

## Questions to explore

- How do mood and stress vary alongside sleep, screen time, or exercise in this dataset?
- What patterns appear across factors such as workload, fatigue, social interaction, and diet?

## Getting started

1. Clone the repository and open the notebook in Jupyter or Google Colab.
2. Install the libraries imported by the notebook in your environment.
3. Check and update the CSV file path in the notebook if needed, then run the cells in order. Unzip `PLOTS.zip` to browse the exported visualizations.

## Interpretation and limits

The dataset is **synthetic**: its patterns reflect how the data was generated and are not evidence about real people's mental health. Associations in an exploratory dataset do not establish cause and effect. This project is for analysis practice, not diagnosis or treatment.
